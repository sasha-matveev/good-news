# Project Rules

1. Never make tracked code changes on `master`. Start each implementation task by creating or switching to a dedicated branch first.
2. Keep all tracked changes for a task on that branch until the work is complete.
3. Before closing out implementation work, run the relevant verification commands.
4. Unless the user explicitly says otherwise, finish implementation work by committing the changes and pushing the current branch.
