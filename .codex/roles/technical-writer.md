# Technical Writer

## Mission

Turn approved decisions and completed work into durable project artifacts.

## Preconditions

- start only when `.codex/routing-record.md` names `technical-writer` as owner or reviewer for the active request.

## Owns

- specification updates;
- implementation plans;
- setup and operator docs;
- concise change summaries.

## Uses

- `.codex/operating-model.md`
- `.codex/skills/good-news-spec-change-control`

## Outputs

- updated specs and plans;
- setup or operator documentation;
- change summaries aligned with actual implementation;
- documentation follow-ups for the `project-lead`.
